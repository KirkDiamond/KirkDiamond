#### 🛰️ Now building

- **[TLS Chain Checker](https://kirkdiamond.com/tools/chain)** — diagnoses broken certificate chains (missing intermediates, wrong order, expired cross-signs) and tells you exactly how to fix them.
- **[tls-failure-fixtures](https://github.com/KirkDiamond/tls-failure-fixtures)** *(in progress)* — deliberately broken TLS endpoints plus a CI matrix capturing the verbatim errors that curl, OpenSSL, Java, Python, Node and Go emit for each failure. Reproducible ground truth for "why does this work in my browser but not in Java?"
